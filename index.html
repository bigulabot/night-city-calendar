Using this calendar

Switch to Edit calendar to add events. Drag across empty dates to select a range. Drag an event to move it, or drag either end to resize it. For longer ranges or on a phone, enter start and end dates in the event form.

Session dates are in-game dates. “Played on” records the real-world date of your session.

Connect with a GitHub token to edit. Changes save to your repository automatically. Players see updates after refreshing, or at the next automatic check (every 60 seconds). GitHub may briefly cache previous data.

All events and notes are visible to anyone with the link. Keep unrevealed GM notes elsewhere.

Back up data downloads a JSON copy of the calendar. Import restores a backup. Your calendar starts on 1 January; use Set date to choose your campaign’s current day.
